# Project guidance

## Purpose
Undergraduate PHYS 220 computational methods project combining analysis of published PSMA radiopharmaceutical clinical trial summaries with a separate educational radioactive decay and clearance simulation.

## Work efficiently
- Keep the project small enough to finish and explain in a short student video.
- Prefer Python scripts and familiar libraries; avoid a web app, frameworks, or paid APIs unless requested.
- Read only relevant files. Batch independent checks and avoid repeating successful checks without a reason.
- Use focused verification proportional to the change. Avoid elaborate tests for documentation or simple formatting.
- Do not use subagents unless specifically requested by the user, except a focused review explicitly required by an applicable skill.
- Give concise updates and explain important equations and code at an introductory Python level.
- Never claim an exact cost or remaining credit balance without access to that information.

## Scientific integrity
- Clearly distinguish published clinical observations from simulated data in filenames, tables, plots, and text.
- Cite the original source, population, endpoint definitions, units, and extraction location for clinical numbers.
- Do not fabricate patient records or reconstruct survival curves from medians.
- Do not interpret differences of medians as individual life extension or infer statistical significance from summary values alone.
- Simulated activity and cumulative activity are not clinical efficacy or absorbed dose. Dose requires additional energy, geometry, and mass assumptions.
- Document assumptions, limitations, and numerical errors. Use reproducible outputs.

## Git and public repository
- Make small meaningful commits at completed milestones, after appropriate checks.
- Push completed milestones once the user has connected the intended public GitHub repository and authenticated.
- Never commit credentials, private patient data, virtual environments, caches, or unrelated files.
- Review staged files before committing. Do not rewrite shared history or delete user work.
- Maintain clear run instructions and source attribution so the professor can reproduce the results.
